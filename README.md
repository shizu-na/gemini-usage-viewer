# Gemini Usage Viewer

Google Gemini (gemini.google.com) の現在の使用量と1週間の上限を取得し、拡張機能アイコン上に表示するChrome拡張機能です。

![Screenshot](gemini_usage_checker.gif)

## 機能

* **使用量のバッジ表示**: アイコンをクリックするとバックグラウンドで使用量を取得し、パーセンテージで表示します。
* **状態カラー表示**: 使用量の割合に応じてバッジの色が変化します（緑: 50%未満、黄: 50%〜80%、赤: 80%以上）。
* **ツールチップ表示**: アイコンにカーソルを合わせると、現在の使用量、1週間の上限、およびそれぞれのリセット時間を確認できます。

## データ処理仕様

* **ローカル完結**: 取得したデータはブラウザ拡張機能内での表示にのみ使用します。外部サーバーへの送信やデータ収集は行いません。
* **データ取得処理**: 実行時にバックグラウンドで非アクティブタブを一時的に生成し、`gemini.google.com` へアクセスしてデータを取得します。
* **権限**: 動作に必要な最小限の権限（`scripting` および 対象ドメインへのアクセス）のみを要求します。

## 動作要件

* Googleアカウントにログイン済みであり、Geminiを利用可能な状態であること。
* `https://gemini.google.com/usage` にアクセス可能なプラン・地域であること。

## インストール手順

1. 本リポジトリのソースコードをダウンロード（またはクローン）し、任意のフォルダに展開します。
2. Chromeのアドレスバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
3. 画面右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、手順1で展開したフォルダを選択します。
5. ブラウザ右上の拡張機能アイコン（パズルピース型）をクリックし、「Gemini Usage Viewer」のピン留めをオンにしてください。

## 使用方法

1. 拡張機能のアイコンをクリックします。
2. バッジに「...」と表示され、バックグラウンドで一時タブが開いてデータ取得が行われます。
3. 取得完了後、一時タブが閉じられ、バッジに使用率が表示されます。
